# ShareIt
ShareIt — проект шерингового сервиса. Он помогает пользователям делиться вещами друг с другом. Например, если вам срочно понадобилась дрель, вы можете арендовать её у другого пользователя, оформив бронирование на определенный срок.

## Технологии

* Java 
* Spring Boot 
* Архитектура: REST API, монолит + микросервисы
* Сборка: Maven
* База данных: PostgreSQL
* Работа с базой данных: Spring Data JPA, Hibernate
* Тестирование: MockMVC
* Docker

## Задачи по проекту

Проект реализован в рамках курса по Java-разработке. На нем отрабатывались следующие темы: 

* Работа со Spring Boot и REST API
* Реализация шаблона DTO и его интеграция в архитектуру проекта
* Использование PostgreSQL в качестве основной базы данных
* Настройка и использование Spring Data JPA
* Работа с Hibernate
* Управление транзакциями
* Проведение юнит- и интеграционного тестирования с MockMVC
* Ознакомление с микросервисным подходом — проект разделен на сервисы gateway и server
* Основы работы с Docker и контейнеризацией

Проект создан за 8 недель (теория + практика) и прошел ревью у профессиональных разработчиков.
